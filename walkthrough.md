# Portfolio Website Walkthrough

## Overview
This walkthrough documents the creation and updates of the portfolio website. The site is a responsive, single-page application showcasing the user's resume content with a modern, dark-themed design.

## Features Implemented
- **Hero Section:** Dynamic typing effect, 3D-style blob animation, and call-to-action buttons.
- **About Me:** Highlights education and career goals with badge-style interests.
- **Experience & Education:** Connected timeline layout for clear chronological display.
- **Skills:** Animated progress bars categorizing technical skills.
- **Projects:** Grid layout with hover effects, showcasing recent work.
- **Diabetes Prediction Project:** Added a new project card with a direct "Demo" link to the live prediction app.
- **Certifications:** Grid display of key achievements.
- **Contact:** Clean card-based contact options.

## Verification
### Responsiveness
- Checked on Mobile (375px), Tablet (768px), and Desktop (1200px+).
- Navbar collapses into a hamburger menu on smaller screens.
- Grid layouts (Projects, Skills) stack vertically on mobile.

### Interactivity
- **AOS Animations:** Elements fade up or zoom in upon scrolling.
- **Typed.js:** dynamic text in Hero section ("AI & Software Developer", "Python Enthusiast").
- **Hover Effects:** Buttons, project cards, and timeline items react to mouse interaction.
- **Demo Link:** The "Demo" button on the Diabetes Prediction project opens the external URL in a new tab.
