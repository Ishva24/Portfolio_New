# ishva.works — Portfolio

Personal portfolio for **Ishva Chinnasamy** — AI/ML Engineer & Data Scientist.

**Live:** [ishva.works](https://ishva.works) · **Repo:** [Ishva24/Portfolio_New](https://github.com/Ishva24/Portfolio_New)

## Highlights

- Distinctive **Signal Lab** design (obsidian + violet + mint)
- Recruiter-focused hero with availability pill and impact stats
- Bento-grid About section
- Filterable project gallery with flagship feature card
- Animated counters, scroll progress, active nav, custom cursor
- Fully responsive + `prefers-reduced-motion` support

## Stack

- HTML5 · CSS3 · Vanilla JS
- [AOS](https://michalsnik.github.io/aos/) · [Typed.js](https://github.com/mattboldt/typed.js)
- Fonts: Syne + DM Sans

## Local preview

Open `index.html` in a browser, or serve the folder:

```bash
# Python
python -m http.server 8080

# Node
npx serve .
```

## Deploy

GitHub Pages via `.github/workflows/static.yml`. Custom domain: `www` (see `CNAME`).
